# Screenshot Capture Guide

Capture these screenshots from the live app to populate the README gallery.
Use Chrome DevTools device mode (iPhone 14 Pro / 390x844 for mobile, 1440x900 for desktop).
Set device pixel ratio to 2x for crisp images. Save as PNG.

## Required Screenshots

### showcase/product-showcase.png
Open `showcase.html` in Chrome at 2x zoom. DevTools → ⋮ → Capture full size screenshot.

### showcase/screenshots/dashboard.png
Desktop view of the Dashboard — balance card, allowance runway, and Coachy FAB visible.

### showcase/screenshots/ai-coach.png
AI Coach chat screen with a conversation showing the AI giving budget advice.

### showcase/screenshots/goals.png
Savings Goals page with at least two goals showing progress rings.

### showcase/screenshots/analytics.png
Analytics page with spending breakdown charts and category data.

### showcase/screenshots/mobile.png
Mobile view (390px wide) of the Dashboard. Use Chrome device toolbar.

### showcase/screenshots/dark-mode.png
Dashboard or any feature page in dark mode.

## Tips
- Log in with a populated account so charts and data look real
- Crop to the app viewport — no browser chrome
- File size: optimize with TinyPNG or similar before committing
